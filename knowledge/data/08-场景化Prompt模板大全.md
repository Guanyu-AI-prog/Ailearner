# 场景化 Prompt 模板大全

学好提示词工程，AI 效率翻倍。以下按场景整理了经过验证的 Prompt 模板，可直接复制使用。

## 一、文章修改 / 润色 / 重写

```
你是一位资深编辑，擅长把握语气和风格。请帮我{修改/润色/重写}以下文章。

## 要求
- 保持原文的核心信息不变
- 让语言更流畅自然
- 语气：{正式/半正式/亲切/幽默}
- 字数：{不超过 X 字 / 不限制 / 精简到 X 字}
- 目标读者：{目标读者描述}

## 原文

{你的文章内容}

请直接输出处理后的结果，不要加额外说明。
```

> 适用：领导发言稿、客户邮件、公众号文章、小红书文案

## 二、文档总结 / 提炼核心

```
请帮我总结以下文档。

## 要求
- 提取核心观点和关键数据
- 控制在 {300 字 / 500 字 / 1000 字} 以内
- 列出 3-5 个要点
- 指出可能的行动建议

## 文档

{你的文档内容}

请以「要点列表 + 一句话总结」的格式输出。
```

> 适用：会议纪要、研报、论文、长篇周报

## 三、邮件 / 公文写作

```
帮我写一封{邮件/通知/汇报/申请}。

## 场景
- 收件人：{收件人/部门}
- 目的：{写这封邮件的核心目的}
- 语气：{正式/半正式/亲切}
- 我方的身份：{你的身份或职位}
- 必须包含的信息：{关键信息点}

请写出完整的{邮件类型}，包含标题和正文。
```

> 适用：工作邮件、请假申请、汇报邮件、商务沟通

## 四、翻译

```
请将以下内容从{源语言}翻译成{目标语言}。

## 要求
- 保持原文的语气和风格
- 专业术语使用{领域}领域的标准译法
- 符合目标语言的表达习惯
- 如果原文有歧义，加注释说明

## 原文

{待翻译的内容}

直接输出翻译结果即可。
```

> 指定领域（技术/法律/医学/营销）能大幅提高术语准确度

## 五、数据分析 / 报告生成

```
请分析以下数据。

## 背景
{数据背景说明}

## 数据
{你要分析的数据}

## 要求
- 找出关键趋势和异常点
- 用表格呈现核心指标
- 给出数据支持的 actionable 建议
- 假设阅读者是：{技术团队/管理层/非技术背景的决策者}

先列出核心发现，再展开分析。
```

> 适用：销售数据、运营数据、用户调研结果

## 六、创意写作 / 文案

```
请帮我写一个{故事/广告文案/标题/宣传文案}。

## 基本信息
- 主题：{创作主题}
- 风格：{幽默/严肃/温暖/专业/文艺}
- 目标读者：{目标读者}

## 关键词（必须包含）
{关键词列表}

请直接输出创作内容。可以给我 3 个不同风格的版本。
```

> 适用：品牌标语、小红书笔记、公众号标题、视频脚本

## 七、学习辅导 / 答疑

```
我正在学习{主题}。请帮我：
1. 用最简单的语言解释{概念}
2. 给一个生活中的类比帮助理解
3. 出 3 道自测题（附答案）
4. 推荐下一步学什么

我的基础：{零基础/初级/中级/高级}

请用通俗易懂的方式回答，避免过多专业术语。
```

> 适用：任何学科的学习，让 AI 变成私人导师

## 八、编程辅助

```
请帮我{写一段代码/解释这段代码/调试这个错误}。

## 背景
- 编程语言：{语言}
- 我目前的水平：{零基础/能看懂/能写简单/有经验}

## 需求
{需求描述}

请先给出方案思路，再提供完整代码，最后说明如何运行。
```

> 零基础也能用，要求 AI 写代码并解释每行在做什么

## 核心心法

1. **具体 > 模糊**：需求越具体，AI 输出质量越高
2. **给角色 + 给要求 + 给格式**：三段式 prompt 保底
3. **迭代追问**：第一次不满意就加「再简洁一点」「更专业一点」
4. **保存模板**：高频场景保存模板，每次改参数即可
