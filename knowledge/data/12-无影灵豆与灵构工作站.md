# 无影灵豆与灵构工作站

> 来源：2026-10 无影个人版控制台实测 + 官网价目表
> 本文只讲**灵豆计费**和**灵构工作站**；套餐订阅价和选型对比见《云电脑/服务器选择指南》。

---

## 一、先分清三样东西

新手最容易混的就是这三个：

| 名称 | 是什么 | 怎么花钱 |
|------|--------|----------|
| **无影云电脑** | 按月/季/年订阅的固定配置 | 人民币，套餐价（黄金款 ¥9.9/月起） |
| **灵构工作站** | 按量计费的 GPU 机器，在「灵构专区」 | **无影灵豆**，开机才扣算力 |
| **无影灵豆** | 签到/活动拿到的通用额度 | 不用充钱也能用，两样都能买 |

一句话：**云电脑是月租，灵构是按小时买豆，灵豆是这两样通用的钱。**

---

## 二、灵构工作站价目表

按量计费，2026-09 官方控制台截图实测。全部 RTX 5880 系列，每档都赠 **100GiB 系统盘 + 40GiB 数据盘 + 40Mbps 带宽**：

| 显存 | vCPU / 内存 | 豆/小时 |
|------|-------------|---------|
| 8GiB | 16 核 / 32GiB | **16.38** |
| 16GiB | 32 核 / 64GiB | 28.98 |
| 24GiB | 32 核 / 64GiB | 41.58 |
| 48GiB ×1 | 32 核 / 64GiB | 58.38 |
| 48GiB ×2（96GiB） | 64 核 / 256GiB | 150.78 |
| 48GiB ×4（192GiB） | 96 核 / 384GiB | 272.58 |

> 价目随时会调，以灵构专区实际显示为准。

**加磁盘会额外消耗灵豆。** 表里的单价对应的是基础配置：**赠送 100GiB 系统盘 + 40GiB 数据盘 + 40Mbps 带宽**。想要更大的盘就用页面上的加号自己加 GiB，加多少、灵豆按多少另计。

所以盘不是白给的——要 500G 数据盘就别默认它免费，得算进预算里。

## 三、计费规则（最容易踩坑的地方）

| | 云电脑 | 灵构工作站 |
|---|---|---|
| 算力 | **不用不扣费** | **开机才扣** |
| 磁盘 | 含在套餐里 | **关机也按 0.1 豆/时扣** |
| 超期处理 | 订阅期内不会没 | 关机保留有期限，超期平台自动释放 |

### 坑1：关机不等于停扣费

灵构工作站关机后，**磁盘占用费照扣**，按 0.1 豆/时 × 24 小时算，一个月空转约 **72 豆**。

控制台提示：按量计费工作站关机后平台最多保留一段时间（实测页面提示约 16 天），超期会**自动释放资源**。

所以正确的省豆姿势是——**不用就主动销毁/释放实例，不是关机**。主动释放只损失开机那几小时；不释放则一路扣到自动回收。

### 坑2：账单里的"运行时长"可能是自然流逝

工作站的时长统计里，有一部分是**关机期间的自然流逝时间**，不是真实开机时长。算 ROI 时别把自然流逝当使用量，否则会把成本低估好几倍。

### 坑3：灵豆自己也会过期

签到/活动送的灵豆**有有效期**，不是永久的。别把"没花完"当成资产，**过期就是清零**。用不完就要么尽快用，要么别攒。

### 坑4：免费期结束不等于资源清零

这个反而是好消息：云电脑**订阅到期后，账号里的灵豆依然在，依然可以用豆开灵构工作站**。

套餐到期和豆过期是两件独立的事：
- 订阅到期 → 云电脑不能用，但豆还在
- 豆到期 → 豆清零，跟云电脑用没用无关

### 免费额度怎么花最划算

**第一个月其实也能用到免费 GPU**，只是别指望能多用。灵构工作站的免费灵豆同样能开机，但消耗速度远超直觉。

**能攒多少，取决于你手上几个号。** 单个号签到一个月最多 **480 灵豆**；另外还有活动，邀请好友之类的，一次能给几百灵豆。

| 攒豆方式 | 大约能到 | 够 48G 单卡（58.38/时）开 |
|---|---|---|
| 单号签到一个月 | 480 豆 | 约 8 小时 |
| 3 个号签到一个月 | 约 1440 豆 | 约 25 小时 |
| 多号 + 邀请好友活动 | 2000 豆以上 | 30 小时以上 |

最低的 8G 档（16.38/小时）便宜得多：480 豆能开约 29 小时，2000 豆能开两天多。

**打法：每天签到，攒够了再集中用。**

| 阶段 | 做法 | 为什么 |
|---|---|---|
| 攒豆期 | 只签到、开活动，不开 GPU | 免费额度有限，一开机就烧，拿来做零散实验太浪费 |
| 集中用 | 攒到够跑一次完整实验再开机 | 豆量够了才能真正把模型跑起来，而不是跑两小时就被迫停 |

号少就多攒几个月、或者开低档；号多、或者拉了活动奖励，才值得上 48G 档——48GiB 显存能跑 14B–32B 量化模型，是实打实的算力，值得用三五十小时的豆换一次有意义的实验。

所以上面「灵豆会过期」那条要分情况看：

- **攒几周的量、攒够就集中用掉** —— 合理，这是把免费额度用满的最优解
- **攒着不用、指望以后再说** —— 不行，过期就是清零

签到是零成本动作，没理由不做。每天花 10 秒，攒够一个月就能免费跑一次 GPU。

## 四、订阅到期前必做的一件事

云电脑关停后数据就没了。到期前先做**迁移**，顺序：

1. **盘一遍数据**，分三类：必须迁的（配置、记忆、项目代码）/ 能重建的（依赖、缓存、镜像）/ 可以丢的
2. **能用 Git 的先 push**，一次性解决多环境同步
3. **配置类文件（`.bashrc`、环境变量、密钥）单独留一份**，这些重建成本最高
4. **剩下部分按目标分流**——迁到另一台云电脑、或本地磁盘，别全压在即将到期的那台上

## 五、8G 显存档的真实边界

买之前先对照，别为显存多花钱：

**能跑**
- 7–8B 模型 Q4 量化（约 5GB 显存）
- Whisper large-v3 语音转写（3–5GB）
- 本地 TTS（2–4GB）
- bge-m3 嵌入 + reranker 重排（合计 < 2.2GB）

**跑不动**
- 14B 以上模型
- 视频生成
- 多模型并行

**关键认知**：8G 档真正值钱的是**整机 16 核 / 32G 内存**，不是那 8G 显存。做 RAG 嵌入重排、数据处理、并发 Agent 这类活儿，CPU 和内存比显存重要。

## 六、常驻服务不要放在临时环境

云电脑和豆包这类"会话型/按量"环境会被平台回收，**回收间隔不固定**（实测出现过 11 分钟、71 分钟两次回收）。

| 放哪 | 适合 |
|---|---|
| 长期订阅的云电脑 | 常驻 Agent、对外服务、需要持久记忆的东西 |
| 灵构工作站 / 临时会话环境 | 一次性任务、评测、跑完就释放 |

规则很简单：**要 7×24 在线的，不能放在会自己回收的环境里。**

## 成本控制技巧

1. **先算清两种计费的差别**——云电脑"不用不扣"，灵构"关机也扣"，选错就是白烧豆
2. **不用就释放**，别指望关机止血
3. **按需开机**，用 1 小时就开 1 小时，别整天挂着
4. **灵豆会过期，但攒对方式很重要**：攒够就集中用是合理的，攒着不用才会白瞎
5. **第 1 个月别急着开 GPU**：免费额度少，消耗快，先签到攒一个月再集中用
6. **本地 API 多通道冗余**，GPU 只在真有必要时才上——大模型推理用 API 通常比开 GPU 便宜几十到几百倍

## 关键洞察

1. **云电脑到期 ≠ 失去算力**：豆还在，可以转成灵构按量用
2. **豆会过期，但"限时"不等于"不能攒"**：攒够一个月集中用，是免费额度最优的用法；真正该避免的是攒着不用等过期
3. **第一个月也能开免费 GPU，只是撑不久**：灵豆消耗快，与其开机两小时烧光，不如每天签到攒一个月再集中跑
4. **关机是最贵的状态**：磁盘费照扣，自动释放前一直在扣
5. **显存不是稀缺资源，内存和CPU才是**：8G 档跑 RAG 嵌入重排完全够
6. **先确认有没有 GPU 刚需再买**：99% 的学习和轻量开发用不到独立显卡
7. **盘不是白给的**：基础价含赠送磁盘，加盘要另计灵豆，要大存储得算进预算
