## 搭建步骤

### 第一步：基础环境（10分钟）
```bash
# 安装Python
sudo apt install python3 python3-pip

# 安装Node.js（用于OpenCode）
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install nodejs

# 安装Git
sudo apt install git
```

### 第二步：AI工具（30分钟）
```bash
# 安装Hermes Agent
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

# 安装OpenCode
npm install -g opencode
```

### 第三步：RAG系统（1-2小时）
```bash
# 安装Dify
git clone https://github.com/langgenius/dify.git
cd dify/docker
docker compose up -d

# 或者用纯Python
pip install langchain chromadb openai
```

### 第四步：对接通讯工具（30分钟）
```bash
# 对接微信
hermes gateway setup  # 选择Weixin，扫码登录

# 对接飞书
# 参考OpenCode文档，配置飞书应用
```

## 踩坑记录

### 坑1：微信登录态过期
- **现象**：微信bot突然不回复了
- **原因**：微信iLink Bot的session token过期
- **解决**：重新扫码登录 `hermes gateway setup`

### 坑2：OpenCode baseUrl配置错误
- **现象**：API调用返回"missing api key"
- **原因**：MiMo API需要 `/v1` 后缀
- **解决**：配置 `https://api.xiaomimimo.com/v1`

### 坑3：Docker占用空间太大
- **现象**：系统盘被Docker镜像撑爆
- **解决**：`docker system prune` 清理无用镜像

### 坑4：多台设备同步问题
- **现象**：代码在A电脑，要部署到B电脑
- **解决**：用Git（GitHub私有仓库），配好SSH密钥

## 关键洞察

1. **工具是手段，不是目的**：不要为了用工具而用工具
2. **先跑起来再优化**：不要追求完美架构
3. **善用免费工具**：大部分场景免费工具够用
4. **自动化 > 手动**：能自动化的就自动化
