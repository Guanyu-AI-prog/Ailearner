# AI编程助手对比指南

> 来源：深度使用 Claude Code、Codex、Hermes、OpenClaw 等工具的实战对比

---

## 核心原则

**编程助手是加速器，不是拐杖。** 不会编程的人装上也只能生成一堆跑不起来的代码。先会基础编程（Python入门），再用工具放大效率。

---

## 主流编程助手对比

### 1. Claude Code（Anthropic）

- **底层模型**：Claude（长上下文强）
- **形态**：终端CLI工具
- **擅长**：长上下文、复杂逻辑、重构
- **成本**：付费（需Claude Pro订阅）
- **适合**：有编程基础、需要处理大项目的开发者

### 2. Codex（OpenAI）

- **底层模型**：GPT系列
- **形态**：CLI + VS Code插件
- **擅长**：与GPT生态整合好
- **成本**：按API用量计费
- **适合**：OpenAI生态用户

### 3. Hermes Agent（开源免费）

- **底层模型**：可配置（支持多种API）
- **形态**：终端Agent，可对接微信
- **擅长**：全自动任务执行、日常AI助手
- **成本**：免费，需自备API Key
- **适合**：需要把AI接入微信/日常使用的用户

### 4. OpenClaw（开源免费）

- **底层模型**：可配置
- **形态**：终端工具，可对接飞书
- **擅长**：移动端编码、任务管理
- **成本**：免费
- **适合**：需要在手机上写代码、对接飞书的用户

## 免费平替方案

| 工具 | 成本 | 特点 | 适合场景 |
|------|------|------|----------|
| Cursor | 有免费额度 | 基于VS Code，底层接GPT-4/Claude可选 | 不想折腾、即装即用 |
| Continue.dev | 免费开源 | VS Code插件，可接任意API（如DeepSeek） | 喜欢自控、有国产API |
| 通义灵码 | 免费 | 阿里出品，中文支持好 | 国内用户、注册即用 |
| Codeium | 个人版免费 | 补全速度快 | 日常编码辅助 |

## 选型建议

```
你现在什么水平？
├── 不会编程 → 先学Python基础语法，别急着装工具
├── 会基础编程 →
│   ├── 想免费 → 通义灵码 或 Codeium
│   ├── 想自控 → Continue.dev + DeepSeek API
│   ├── 想要最好体验 → Cursor（免费额度够用）
│   └── 用Claude多 → Claude Code；用GPT多 → Codex
└── 想把AI接微信/飞书 →
    ├── 对接微信 → Hermes Agent
    ├── 对接飞书 → OpenClaw
    └── 用云电脑远程跑 → 无影云电脑部署，手机/平板连接
```

---

## 关键洞察

1. **会用工具 ≠ 厉害**：真正厉害的是知道什么时候该用、什么时候不该用
2. **先学编程再用工具**：AI写的代码有时是屎，需要你能看懂并改对
3. **云电脑是基础设施**：旧电脑/手机 + 无影云电脑，一样跑这些工具
4. **不要追新**：把一个工具用透，比装一堆强
