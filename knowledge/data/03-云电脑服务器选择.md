# 云电脑/服务器选择指南

> 来源：4个月实战，用过5+种云服务

---

## 核心原则

**先免费试，够用就不升级。** 大部分AI学习和轻量开发不需要高配。

**电脑配置不够？用云电脑。** 无影云电脑新用户免费1个月（4核8G），手机、旧笔记本、平板都能远程连接，和用本地高性能电脑完全一样。零成本解决"电脑太差"的问题。

## 我用过的方案

### 1. 无影云电脑（主力）
- **配置**：4核8G，157GB磁盘，Ubuntu 22.04
- **用途**：开发、测试、跑Agent、对接飞书/微信
- **成本**：新用户免费1个月，之后按套餐付费，最低黄金款¥9.9/月（2026-10）
- **优点**：随时可用、预装工具、网络好
- **缺点**：没有GPU、存储有限

### 2. 阿里云服务器（部署用）
- **配置**：2核4G
- **用途**：部署RAG系统、Web服务
- **成本**：约¥80/月
- **优点**：公网IP、稳定、可长期运行
- **缺点**：配置低、没有GPU

### 3. Google Colab（GPU任务）
- **配置**：T4 GPU，12GB显存
- **用途**：跑嵌入模型、测试GPU推理
- **成本**：免费
- **优点**：免费GPU、Jupyter环境
- **缺点**：有时间限制、不稳定

## 选型决策树

```
你要做什么？
├── 学习AI/写代码 → 无影云电脑（免费试用）
├── 跑模型/训练 → Google Colab（免费GPU）
├── 部署Web服务 → 阿里云/腾讯云（¥50-100/月）

└── 长期生产环境 → 买物理服务器或高配云
```

## 踩坑记录

### 坑1：系统盘空间不够
- **现象**：Docker/模型文件把系统盘撑爆
- **解决**：数据盘挂载到 `/data`，模型文件放数据盘

### 坑2：没有GPU跑不动嵌入模型
- **现象**：8G内存跑bge-m3，CPU 99%，等几分钟
- **解决**：用API调用嵌入模型（SiliconFlow免费），不本地跑

### 坑3：云电脑重启后配置丢失
- **现象**：环境变量、定时任务、进程都没了
- **解决**：配置写入 `.bashrc`，用 `crontab` 持久化，重要文件push到GitHub

### 坑4：两台云电脑之间传数据
- **现象**：代码在A电脑，要部署到B电脑
- **解决**：用Git（GitHub私有仓库），配好SSH密钥

## 成本控制技巧

1. **先免费试**：无影云、Colab、Kaggle都有免费额度
2. **按需付费**：GPU任务用AutoDL按小时租，不买月卡
3. **轻量部署**：2核4G够跑大部分Web服务，不用上高配
4. **善用免费API**：嵌入模型、Rerank模型用SiliconFlow免费额度
5. **代码管理**：用Git，避免重复配置环境
