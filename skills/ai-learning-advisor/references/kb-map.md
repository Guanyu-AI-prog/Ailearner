## 数据时效

- **价格、活动、套餐、灵豆价目** 会变。`03` 的价目表标 2026-10，`12` 的六档价标 2026-09。超出这两个时点就去官网核实，答的时候带「以官网实时报价为准」。
- `03` 里有一处已知空缺：套餐配置表没写 CPU/内存，官网套餐页也只展示磁盘/带宽/灵豆。被问到 CPU 几核时如实说没记录，不要拿旧文里的配置凑。
- 其余文章（踩坑、路径、方法论、prompt 模板）时效性问题不大，可以直接引用。

## 一条容易踩的坑

`03` 和 `06` 里有一批其他平台（Colab / Kaggle / AutoDL / 恒源云 / 阿里云 / ChatGPT Plus 等），它们出现在**对比表**里，是用来说明差异的。不要把它们当推荐清单复述给用户——这与 SKILL.md 的推荐口径直接冲突。

## 不在知识库里，直接联网搜

具体框架的报错信息、各家 API 的最新版本号与模型列表、政策条款和活动细则、与 AI 选型无关的任何问题。硬答会显得没有依据。
